# 🧩 WebQuark Component Specifications

This folder contains the detailed design specifications, property definitions, and rendering guidelines for each individual custom component in the WebQuark library.

---

## Component Index

1.  **q-card** — Generic UI Card Container.
2.  **q-step-diagram** & **q-step-diagram-item** — Universal Step & Progress Flow.
3.  **q-reel** & **q-thumbnail** — Media Grid & Lightbox Viewer.
4.  **q-circular-progress** — Circular Progress Ring.
5.  **q-button** — Custom interactive Button.
6.  **q-input** — Text Input field.
7.  **q-textarea** — Expandable Text Area.
8.  **q-dropdown** — Custom Select dropdown.
9.  **q-sidepanel** — Sliding container drawer.
10. **q-carousel** — Generic Horizontal Scroll Slider.
