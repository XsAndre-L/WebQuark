# WebQuark Component Specifications

This folder contains design specifications, property definitions, and rendering guidelines for WebQuark custom components.

## Component Index

1. **q-button** - Custom interactive button.
2. **q-link** - Text-style link for inline and navigation links.
3. **q-toggle** - Binary switches and checkbox-style toggles.
4. **q-card** - Visual content card with elevation.
5. **q-panel** - Structural layout region with header/body/footer slots.
6. **q-navbar** - Responsive top navigation header.
7. **q-form** - Form wrapper with typed submit values.
8. **q-input** - Text input field.
9. **q-textarea** - Expandable text area.
10. **q-dropdown** - Custom select dropdown.
11. **q-sidepanel** - Drawer and persistent side navigation.
12. **q-carousel** - Horizontal scroll slider.
13. **q-data-table** - Standard data grid.
14. **q-dialog** - Dialog overlays and confirmation modals.
15. **q-icon** - Dynamic icon element.
16. **q-quantity-selector** - Numeric step input.
17. **q-scrollable** - Custom scroll container.
18. **q-syntax-box** - Code display/editor with highlighting.
19. **q-reel** and **q-thumbnail** - Media grid and lightbox viewer.
20. **q-step-diagram** and **q-step-diagram-item** - Step and progress flow.
21. **q-circular-progress** - Circular progress ring.
22. **q-tooltip** - Context description bubble.
